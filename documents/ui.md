# UI/UX・ワイヤフレーム仕様書 (User Interface)

## 1. 全体レイアウト方針
視空間認知（VSI）を助け、視線移動（サッカード）を最小化する層状レイアウトを採用。横画面（ランドスケープ）固定とする。

### 1.1 レスポンシブ・スケーリング戦略
* アスペクト比の死守: 仮想キーボードは物理キーボードとの空間的リンクを保つため、キーの縦横比の歪曲を禁止する。
* レターボックス処理: 等倍スケール（Uniform Scaling）で拡縮し、生じた余白はレターボックス（黒帯等のデッドスペース）として処理する。
