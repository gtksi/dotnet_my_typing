# 開発実装計画: ローマ字マトリクス・ビルダー

このドキュメントは、仕様書（`spec.md`, `stack.md`, `ui.md`）に基づいた、Blazor WebAssembly PWA アプリケーションの具体的な実装・設計方針を定義します。

## テーマとゴール
視空間認知（VSI）と流動性推理（FRI）が優位な児童向けに特化し、「空間座標とマトリクス配列」としてタイピングを習得させるアプリケーションを、.NET 10.0 上でシングルテナントのオフラインPWAとして構築します。

## プロジェクト構成 (Architecture)
アプリケーションはMVVM（あるいはBlazor向けのコンポーネント指向アーキテクチャ）を基本とし、状態管理とUIを分離して実装します。

### 1. プロジェクト基盤
*   **テンプレート:** Blazor WebAssembly Standalone App (PWAオプション有効)
*   **フレームワーク:** .NET 10.0
*   **CSSフレームワーク:** 標準のCSS Isolation (`.razor.css`) を使用し、極力外部依存を減らす。横画面固定とスケーリングをCSSカスタムプロパティで管理。

## Proposed Changes (実装するモジュール)

### Model & State (状態管理とドメインロジック)
#### [NEW] `Models/TypingProblem.cs`
出題される文字列と、そのローマ字の正解パターン（ヘボン式・訓令式）を保持するデータクラス。
#### [NEW] `Models/KeyboardState.cs`
現在押されているキーや、ナビゲーション線で光らせるべき対象のキー座標の情報を管理。
#### [NEW] `Services/GameStateService.cs`
現在のステージ進行度、10問セッションの進捗、コンボ数、直近のエラーログなどを保持するシングルトンの状態管理サービス。

### Data Access (永続化)
#### [NEW] `Services/LocalStorageService.cs`
JS Interopを利用するか、既存の NuGet パッケージ（例: `Blazored.LocalStorage`）を利用して、ダッシュボード用のログ情報や現在の閾値設定などをブラウザのローカルストレージに永続化する。

### UI Components (コンポーネント)
#### [NEW] `Pages/Index.razor`
アプリのエントリーポイント。ユーザーのステートに応じて、メインプレイ画面かダッシュボード画面への切り替えをルーティング。
#### [NEW] `Components/VirtualKeyboard.razor`
仮想キーボードのUI。絶対座標を死守したSVGまたはFlexboxによるレイアウト。F/Jのアンカーエフェクトと、母音のアクティブ状態をバインディング。
#### [NEW] `Components/MatrixDisplay.razor`
ローマ字マトリクス（子音×母音）のパネル。獲得したマトリクスを色付け。
#### [NEW] `Components/Dashboard.razor`
10問終了後に遷移するリザルト画面。児童向けへのポジティブなフィードバックの表示と、指導者（管理者）モードへの切り替えボタンを保持。

## 開発・構成ステップ (Roadmap)
1.  **Phase 1: プロジェクトの雛形とPWA設定**
    *   `dotnet new blazorwasm -pwa` コマンドによるプロジェクトの初期化。
    *   ManifestやService Workerの基本設定。
2.  **Phase 2: UIレイアウトとキーボードバインディング**
    *   ブラウザのキーボードイベントのキャッチロジックの実装（`@onkeydown` 等）。
    *   仮想キーボードコンポーネントの構築と、押下状態の視覚化（ブザー音制御含む）。
3.  **Phase 3: コア・プレイロジックの構築**
    *   出題エンジン、ヘボン式/訓令式の両許容判定ロジックの実装。
    *   1セッション（10問）完了までのライフサイクルとコンボ制御。
4.  **Phase 4: ダッシュボードと自動ステージ進行**
    *   90%等の閾値に基づく次行の自動アンロック処理。
    *   ローカルストレージを用いたデータの保存と読み出し。
