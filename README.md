# ローマ字マトリクス・ビルダー (RomanMatrixBuilder)

## アプリ概要
タイピング習得PWAアプリケーションです。
時間を競うのではなく、「座標とマトリクス配列のパズル」としてローマ字入力の仕組みを理解・習得できるように設計されています。

## アプリの基本ルール

このアプリケーションは、タイピングを「反射神経のゲーム」ではなく、「空間座標の把握」と「子音×母音のマトリクスを埋めるパズル」として習得するための支援アプリです。以下の基本ルールに基づいて設計されています。

1. **時間制限なし**
   タイムリミットや文字の落下など、時間を急かす要素は一切ありません。「正答率（Accuracy）」と「連続正解数（コンボ）」を大切にします。
2. **視覚的なエラーリカバリー**
   誤入力した際にブザー音や過度な画面の揺れなどで罰を与えることはありません（小さく「カツッ」と鳴るのみ）。その代わり、次に打つべき正しいキーへの「光る道筋（ナビゲーション線）」が再提示されます。
3. **ヘボン式・訓令式の両対応**
   画面上のローマ字の提示は原則「ヘボン式（SHI, CHI, TSUなど）」ですが、実際のキー入力は「訓令式（SI, TI, TUなど）」で打っても正解として許容されます。
4. **1セット10問とステップアップ**
   1回のプレイは「10問で1セット」です。10問終わるごとにリザルト画面（ダッシュボード）が表示され、達成感を味わえます。正答率が基準を満たせば、自動的に次の行（か行、さ行…）へ進みます。
5. **完全プライベート（シングルユーザー運用）**
   学習データはプレイしている端末（ブラウザ）の中にのみ保存されます。他の端末との同期や複数人での共有機能はありません。

## 開発環境と技術スタック
* **フレームワーク**: ASP.NET Core Blazor WebAssembly (.NET 10.0)
* **アーキテクチャ**: PWA (Progressive Web App) + LocalStorage (オフライン動作)
* **言語**: C#, HTML, CSS
* **永続化**: Blazored.LocalStorage (セーブデータ管理)
* **CI/CD**: GitHub Actions (GitHub Pages への自動デプロイ)

## 実行方法
1. .NET 10.0 SDK をインストール。
2. リポジトリをクローンし、プロジェクトフォルダで `dotnet run` (または `dotnet watch`) を実行します。
3. ブラウザで `https://localhost:port` にアクセスし、PWAとして「ホーム画面に追加（インストール）」することでフルスクリーンで学習を開始できます。
